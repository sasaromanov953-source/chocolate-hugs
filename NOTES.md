## Как устроено

- Заставка: 218 кадров WebP рисуются на canvas по прокрутке
  (`assets/hero/d` для компьютера, `assets/hero/m` для вертикальных экранов).
- Логотип: исходный вектор без изменений, используется как маска,
  цвет задаётся из палитры (`assets/img/logo.svg`, `logo-mark.svg`).
- Цвета: розовый `#EFD0D6` и какао `#604340` взяты из файлов логотипа.
- Запуск локально: `python3 -m http.server` в корне и открыть `http://localhost:8000`.
